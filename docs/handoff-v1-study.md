# Handoff：台灣視角的累積 + 提領策略研究

給 Claude Code 的研究規格。目標不是產出一個「最佳解」，是產出一組**在明確假設下可複現、且知道自己在哪裡會錯**的機率分布。

---

## 0. 這份研究要回答什麼

主問題：對一個以台幣生活的人，在 50 年的累積 + 提領全程中，哪一組（資產配置 × 提領規則）能在**不讓實質生活水準跌破地板**的前提下，最大化終身實質提領總額？

**不要**用「生存率」當主要指標。動態提領規則的機制就是拿支出換生存，只看生存率等於只計分收益、不計分代價，接近循環論證。指標定義見 §5。

### 待驗證的假說（研究要直接回答這幾條）

| ID | 假說 | 為什麼重要 |
|---|---|---|
| H1 | 現金水池（bucket）策略在**移除前視偏誤**後，優勢是否還存在 | 既有實作用當年報酬決定當年是否動用水池，等於白送擇時能力 |
| H2 | Cederburg「全股票優於目標日期基金」的結論，換成**台幣計價 + 台灣 CPI + 無美國社安**之後是否還成立 | 原論文的隱含地板（美國社安）在台灣不存在 |
| H3 | BND（美元、存續期約 6 年）作為緩衝資產，是否劣於**台幣短天期**工具 | 2022 年 BND −13%；且它的匯率風險與支出幣別不匹配 |
| H4 | 累積期加入**與市場相關的收入中斷**，會讓成功率掉多少 | 失業與股災同時發生才是真正的破產路徑 |
| H5 | 支出可壓縮比例降到多少時，GK 這類護欄規則失效 | GK 的成功率是拿支出換來的，而支出不是全部都能砍 |

**硬性要求：拼接段必須留下 provenance 欄位**（哪一段用哪個來源），並且對重疊期做相關性/差異驗證，寫進報告。你在信貸那篇做過這件事（1997–2002 近似段對 2003–2008 真值，月相關 0.9953），照同樣標準做。

優先順序：官方來源 > 學術資料庫 > 商業 API。若某段取不到，**寧可縮短樣本並明說，不要用生成資料填補**。所有下載腳本要可重跑，原始檔存 `data/raw/`，處理後存 `data/processed/`，中間步驟不可手動編輯。

## 2. 模擬引擎

### 2.1 重抽方法
**Stationary block bootstrap**（Politis–Romano），區塊長度服從幾何分布，平均長度掃 `[12, 24, 36, 60]` 個月做敏感度。

**綁定同一條時間軸**：所有序列（股、債、現金利率、匯率、台灣 CPI）用**同一組月份索引**抽取。抽到 1974-09，就是那個月的股票、債券、匯率、通膨一起被取用。這一點不容妥協——H2、H3 的答案完全取決於通膨與資產報酬的共變異數。

實作建議：先組成一個 `(T, K)` 的月度矩陣，只對**列索引**抽樣，不對欄位分別抽。

### 2.2 時序規則
- 提領在**期初**發生，按月，不是年底
- 所有決策只能使用 **t−1 期末以前**的資訊。寫一個 `assert` 檢查任何策略函式的輸入不含當期報酬
- 再平衡：對照日曆式（年度）與帶寬式（±5pp），至少報一組

### 2.3 路徑數
主結果 100,000 條；敏感度分析與變因拆解 200,000 條。報告二項標準誤，**成功率不報到小數點後一位以下**。

## 3. 「貼近真實生活」的模組（本研究的核心差異）

這一節是這份研究跟一般 4% 法則回測的分野。每一項都要能開關，並各自跑一次「開 / 關」的邊際影響。

### 3.1 收入衝擊與市場相關（累積期）
- 基準年失業機率 `p0`（建議 2–3%）
- 市場處於 −20% 以上回撤時，機率上調至 `p0 × k`（k 掃 2–4）
- 失業持續 6–18 個月（抽樣），期間**停止投入**，並從緊急預備金提領
- 若預備金耗盡則被迫賣出部位（在低點）

這是 H4 的全部內容，也是既有所有模型共同缺的那一塊。

### 3.2 支出拆成地板與彈性
```
total_spending = floor_spending + discretionary_spending
compressibility = discretionary / total     # 掃 0.2 / 0.35 / 0.5
```
- 動態規則（GK 等）**只能砍 discretionary**
- 定義「破產」不只是資產歸零，也包括**實質支出跌破 floor**（見 §5）
- `floor_spending` 隨台灣 CPI 調整，不可凍結

### 3.3 台灣稅制
- 海外所得（VT/BND 配息、實現損益）：全戶全年達 100 萬即全數計入基本所得額；基本所得額超過 750 萬部分以 20% 計算基本稅額，與一般所得稅額擇高
- 免稅額與門檻要參數化（會隨 CPI 調整），並在報告中標註採用的年度
- 提領來源順序（先賣什麼）會影響稅負 → 這本身就是一個可比較的策略維度
- **提醒**：稅制細節以當年度法規為準，模型中要留一個 `tax_disclaimer` 欄位提醒結果對此敏感

### 3.4 年金地板
- 勞保年金 + 勞退：65 歲起，實質金額參數化
- **必須跑三個情境**：足額 / 打七折 / 歸零
- 這是 H2 的關鍵槓桿。Cederburg 的「100% 股票」是建立在美國社安這個巨大類債券部位之上的；台灣版的地板小得多且有財務疑慮，如果打七折就翻盤，這個發現本身比任何配置建議都重要

### 3.5 匯率
支出是台幣，資產是美元。不要把匯率當噪音——它與台灣 CPI、與全球股市都有結構關係，必須跟在同一條抽樣時間軸上。另外要測「台幣長期結構性升值 / 貶值」各 1%/年的情境。

### 3.6 成本
ETF 內扣、複委託或 IBKR 手續費、換匯價差、再平衡成本。全部參數化，預設值寫進報告。

### 3.7 晚年醫療支出（選配，但建議做）
75 歲後實質支出以固定斜率上升，或以低機率抽取大額一次性衝擊。這會改變「後期是否該保留債券」的答案。

### 3.8 行為放棄（選配，做出來很有價值）
若回撤超過 X% 且持續 Y 個月，以機率 `q` 觸發「放棄策略、全部轉現金」。這把「你會不會照做」變成可量化的變數，而不是免責聲明。

## 4. 策略矩陣

分階段跑：先做**篩選層**（少數代表性組合 × 中等路徑數），淘汰明顯劣勢者，再對存活者做完整 factorial。不要一開始就跑滿。

### 4.1 累積期配置
- `A1` 60/40 固定
- `A2` 80/20 固定
- `A3` 100% 股票
- `A4` bond tent：100% 股票 → 退休前 10 年線性滑到 80/20（退休後再滑回）
- `A5` 退休前 100% 股票 → 退休時 60/40 → 逐年上升至 80/20（rising equity glide，Pfau–Kitces）

### 4.2 提領期配置
- `P1` 60/40（VT + BND）
- `P2` 80/20（VT + BND）
- `P3` 100% VT + **台幣**現金桶，桶深度 N ∈ {2, 3, 5} 年
- `P4` 100% VT + 台幣短債階梯（5 年）
- `P5` rising equity glide

`P3`/`P4` 的補桶規則必須明確且**無前視**。建議：以「總資產相對歷史高點的比值」為條件（例如高於前高 95% 才補桶），而不是「今年股票漲」。這是 H1 的關鍵設計。

### 4.3 提領規則
- `W1` 4% 起始 + 通膨連動（baseline，不做動態）
- `W2` **完整 GK 四規則**：portfolio management / inflation / capital preservation（−10% 且跳過通膨）/ prosperity（+10%），含最後 15 年停用 capital preservation 的原始設定。**不要**只實作「凍結通膨調整」就叫 GK
- `W3` Vanguard dynamic spending：上限 +5% / 下限 −2.5% 的年度變動帶
- `W4` VPW / 攤銷法（依剩餘年期與預期報酬重算）
- `W5` RMD 式：每年提領固定比例的當期資產
- `W6` funded ratio 護欄：以「資產 / 剩餘終身支出現值」觸發，而非提領率

### 4.4 起始提領率
掃 `2.5% ~ 5.0%`，步長 0.25pp。對每個策略找出**在指標門檻下的最大可持續起始提領率**，這比固定 4% 再比成功率更有資訊量。

## 5. 指標定義（重要）

### 5.1 主要指標
1. **終身實質支出總額的 5th percentile**（壞情況下你實際過的日子）
2. **終身實質支出總額的中位數**
3. **P(實質支出跌破 floor 至少一年)** ← 這是真正的「失敗」定義
4. **實質支出低於初始值 80% 的年數佔比**（中位數與 90th percentile）
5. **P(資產於 50 年內耗盡)**
6. **CRRA 效用下的確定等值支出（certainty equivalent）**，γ ∈ {2, 4, 8}

指標 6 是把「最大化提領」與「最大存活」兩個衝突目標合併的原則性做法。γ 掃描本身就是結果——若排序在 γ 之間翻轉，那代表沒有唯一最優解，這也要老實報。

### 5.2 次要指標
- 期末實質財富（遺產）分布
- 最大回撤（帳面）分布
- 首次觸發減支的年份分布
- 有效稅率

### 5.3 報告規則
- 全部以**實質台幣**呈現。名目數字不出現在主表
- 每個成功率附二項標準誤
- 任何兩策略差距小於 2×SE，一律寫「無法區分」，不排名次

## 6. 防自欺協定

這一節的地位跟前面同等，不是附錄。

1. **前視檢查**：策略函式簽章只接受 `history[:t]`，用 assert 強制。寫一個故意違規的測試確認它會被抓到
2. **零波動退化測試**：把所有波動設為 0，結果必須精確等於解析年金公式
3. **文獻對照**：關掉台灣模組、用美國資料 + 30 年期，必須複現已發表的 4% 法則成功率（約 95%）。對不上就是引擎有問題，不要繼續往下做
4. **變因拆解**：每個「貼近真實」模組（§3.1–3.8）各跑一次開/關，量化它單獨貢獻幾個百分點。像信貸那篇把報酬與通膨拆開一樣
5. **收斂報告**：路徑數 1k / 10k / 100k / 200k 的結果表，證明主結論不是抽樣雜訊
6. **獨立複核**：核心引擎（重抽 + 提領迴圈）由一個沒看過實作的 session 依規格重寫，對數字。兩版差異寫進報告
7. **未建模清單**：明確列出沒算的東西（台海風險、長照制度變動、稅制修法、遺產規劃、房產、通膨與匯率的長期結構性轉折）

```
├── experiments/

│   └── full.py            # 完整 factorial
├── results/               # tables + figures（實質台幣）
└── REPORT.md
```

`REPORT.md` 結構：
1. 一句話結論 + 它成立的前提
2. H1–H5 逐條回答，附數字與 SE
3. 主表：策略 × 指標
4. 變因拆解（哪些假設貢獻了多少）
5. 敏感度：哪一個參數改變會翻轉結論
6. 未建模清單與已知偏誤方向

**最後一項最重要**：對每一個已知偏誤，說明它是讓結果偏樂觀還是偏悲觀。信貸那篇的所有殘留偏誤都指向「讓策略看起來更好」，這個模式本身就是資訊。
