# Handoff v4：補齊候選集，把「活多久」放進來

延續 v1–v3 與專題 A/B/C。引擎已驗證（無前視含作弊偵測、零波動＝解析年金、質借手算複現、文獻關卡 97.9%），計分已改絕對地板、CRRA γ∈{2,4,8} 已報。**v4 原則上不動核心引擎，動的是：候選策略、壽命模型、資料樣本。**

v3 之後的局面：VPW/RMD 支配 GK、桶被證明無效、動態規則在 floor_ratio ≥ 0.7 失效。這三件事把問題收斂成一句話：

> **對「砍不掉的支出佔比高」的人，動態規則家族沒有答案；對其他人，VPW 贏在總量、輸在平滑。**

所以 v4 要回答兩件事：(1) 高 floor_ratio 的人用什麼（地板＋上檔）；(2) VPW 的平滑能不能補，而且不付出 GK 那麼大的代價。其餘項目是讓答案更接近真實。

優先序是刻意的：§1–§3 決定「推薦什麼」，§4 之後決定「推薦的東西在真實世界會不會被打折」。

### 0.2 勞退月領的建模更正（影響專題 A/B 與 §1 全部）

## 1. 最高優先：地板＋上檔家族（v3 §7，S1–S4）

v3.3 已證明 floor_ratio ≥ 0.7 時 GK 失效。這一族是那群人的唯一正解候選，也是本研究可能最大的結論翻轉。

### 1.1 策略定義

```
S1  勞保年金當地板 + 其餘 100% 股 + VPW
    勞保實質金額參數化；必跑 足額 / 打七折 / 歸零 三情境
    勞退依 §0.2 建模為定期給付
S2  台幣公債/定存階梯覆蓋地板支出 N 年（N ∈ {10, 15, 20}），其餘 100% 股 + VPW
    階梯到期後的地板由剩餘股票資產以 VPW 接手
S3  遞延年金：60–65 歲買入，80/85 歲起終身給付
    查台灣現有商品（壽險公司遞延年金、利變年金）的實際給付率；
    查不到可用商品就用精算公平價 × (1 − 附加費用率 ∈ {10%, 20%, 30%}) 標為假設性
S4  S1 + S2 疊加；S1 + S3 疊加
```

### 1.2 比較基準與假說

- 對照組：v3 最佳的 VPW(3%) 60/40、80/20，以及 GK4/GK5
- floor_ratio ∈ {0.35, 0.5, 0.7, 1.0}，逐格比較

**先驗預期（要被檢定）：** 地板族的「跌破地板率」應遠低於動態規則，代價是中位數終身支出較低。

- 若 floor_ratio = 0.7 時代價 < 中位數 15%，這一族**支配**動態規則家族 → 報告頭條改寫
- 若代價很大，要拆解是「地板資產報酬太低」還是「年金附加費用吃掉」

### 1.3 輸出
一張「floor_ratio × 策略」主表（跌破地板率、p5/中位終身支出、CE γ=4），以及一張「地板成本 vs 地板保障」的前緣圖。

## 2. 壽命進主結論（v3 §8.1，專題已做、主結論未做）

目前 v1–v3 主結論仍把「活滿 50 年」當確定事件。

### 2.1 做法
```
存活年數：內政部最新簡易生命表抽樣（單身 / 雙人聯合）
主指標：P(資產耗盡 且 仍存活)、P(跌破地板 且 仍存活)
另報：「活到 p90 年齡」的條件結果
```
退休年齡掃 {40, 50, 60, 65}。

### 2.2 生命表偏誤修正
簡易生命表是當期表，會低估世代壽命；高所得族群又比全體長壽。

```
longevity_shift ∈ {0, +3, +6} 年（整體平移存活曲線）
```
**排序若隨 shift 翻轉，標為不穩健。**

### 2.3 預期
對 65 歲退休者，固定 50 年大幅高估風險；對 40 歲 FIRE 者低估。**目前報告對兩者給同一個答案，這一節要把答案拆開。**

## 3. 動態規則補完：平滑層與新對手

v3 說 GK 剩下的價值只有「支出平滑」。v4 要檢驗：**能不能在 VPW 上加平滑，拿到 GK 的平滑、保住 VPW 的總量。** 桶已證明不是平滑工具（v3.2），平滑只能做在支出規則上。

### 3.1 VPW + 平滑層
```
V-cap   Vanguard 式：年支出變動上限 +5% / 下限 −2.5%（再掃 {+5/−5, +10/−5}）
V-yale  耶魯式：今年 = α × 去年支出(通膨調整) + (1−α) × VPW 算出值，α ∈ {0.5, 0.7, 0.8}
V-floor VPW 但實質支出不低於地板（地板由 S1/S2 提供時才有意義，與 §1 交叉）
```
新增「支出平滑」指標，讓 GK 的優勢能被量化比較：
```
spend_vol     = 年實質支出變動率的標準差
spend_dd_max  = 支出自高點最大回撤
spend_dd_yrs  = 支出低於高點 80% 的累計年數
```
**判定：** 若 V-cap 或 V-yale 的 spend_vol ≤ GK 且 p5/中位仍勝 GK，GK 在本研究中失去最後存在理由。

### 3.2 台灣版 RMD（生命表驅動、每年更新）
```
N_t = 當年齡平均餘命（最新簡易生命表）+ buffer，buffer ∈ {0, 5, 10}
提領 = 資產 / 年金現值因子(r, N_t)
r：VT 預期實質報酬（固定 5.0% 與 1/CAPE 兩版）
```
與 VPW（固定到 100 歲）比較。

### 3.3 規劃期延長的斷崖測試
驗證「固定終點 + 事後延長」的代價：
```
VPW 到 100 歲；90 歲延到 110、100 延到 120、110 延到 130（存活時才觸發）
對照：§3.2 每年平滑更新、S3 遞延年金
```
紙上試算（固定 4% 實質）顯示每次延長砍約四成支出、130 歲剩初始約 6%。**用真實序列確認量級，並證明「每年平滑更新」或「年金地板」能消除斷崖。**

### 3.4 W6 funded ratio 護欄與風險基礎護欄
```
W6  funded_ratio = 資產 / 剩餘終身支出現值；< 0.8 減支 10%，> 1.2 加支 10%
W7  風險基礎護欄：用引擎內嵌的快速估計算「成功機率」，< 70% 減支、> 95% 加支
    （成功機率估計只能用 t−1 以前的資料，必須過無前視測試）
```
W7 是美國實務界從 GK 演進的方向，若它在絕對計分下仍輸 VPW，那是對實務界有意義的結論。

## 7. 新題：Return stacking（RSSB + RSST 五五配）

目標：100% 股 + 50% 公債 + 50% 趨勢，對照 VT 單持與 60/40。實績僅約三年（2023-09 / 2023-12 上市），只能驗證執行，不能驗證策略，所以用合成序列。

### 7.1 合成
```
股票：現有股票序列（JST 版本可用時優先）
公債疊加：10 年債報酬 − T-bill（已有 Shiller GS10 與 TB3MS）
趨勢疊加：SG Trend Index（2000+）；更早用 AQR 公開的 TSMOM 因子資料，
          能取得的最長世紀序列再往前接；拼接點做重疊期驗證並記入 PROVENANCE
融資成本：T-bill + spread，spread ∈ {0, 0.5%, 1%}
費用：RSSB 約 0.40%、RSST 約 1.0%（實作時查最新）
```

### 7.2 要回答
- 1966–1982 型通膨體制下，公債疊加與趨勢疊加各自是幫忙還是放大損失
- 2022 型股債同跌年，趨勢那一半補回多少
- 搭配 VPW 提領時，槓桿組合的支出波動是否大到抵銷總量優勢
- 與「80/20 VT+BND」在 CE γ∈{2,4,8} 下的排序

**提醒：** 合成序列是理想化上限，真實 ETF 有追蹤誤差與清算風險，結論要打折標示。

## 9. 真實性模組（v3 §8.2、§8.4–8.6）

依「改變結論的可能性」排序：

### 9.1 行為棄守
```
回撤 > X% 且持續 > Y 月 → 以機率 q 全部轉現金，之後以機率 m/月 回場
```
對 100/0、VPW（支出大幅浮動）與 GK 都偏樂觀。**這是唯一能把「你會不會照做」變成數字的地方。** VPW 支出波動大，可能比 GK 更容易觸發棄守——與 §3.1 平滑層交叉檢驗。

### 9.2 稅與費用
```
海外所得納入基本所得額（最低稅負制門檻，實作時查最新金額）
美國 ETF 股息預扣 30%、美國遺產稅（非居民 6 萬美元門檻）
ETF 內扣：VT vs 009826 差距見 docs/vt-vs-009826-costs.md
換匯價差、再平衡成本
```
高周轉策略（GK、質借、槓桿組合）相對受傷更多。

### 9.3 支出微笑曲線
實質支出 −1%/年、75 歲後 +2%/年等形狀參數化。預期會讓固定提領看起來較好、削弱動態規則優勢——這是目前對動態規則有利的隱藏偏誤，要量化。

### 9.4 樣本延長
Shiller 補到最新、FRED 補到最新。**報告同時給含與不含 2024 以後的版本**，避免用近期多頭美化結論。009826 已掛牌（2026-08），但樣本過短，只記錄追蹤誤差，不進引擎。
