# Handoff v2：質借提領 × 三條抵押路徑 × 機會式補桶

延續 `retirement-study-handoff.md`（以下稱 v1）。v1 的資料層、綁定時間軸的 block bootstrap、貼近真實模組、指標定義、防自欺協定**全部沿用**，本文件只描述新增與修改的部分。

---

## 0. v2 新增了什麼

v1 比較的是「賣股 vs 動態提領規則」。v2 加入第三種提領來源：**不賣、不領息，用部位質借**。並且把「借款這件事本身」拆成三條在台灣實際存在的路徑，因為它們的利率、幣別、稅務、強制平倉機制完全不同——**這三條路徑的差異，很可能比任何提領規則的差異都大。**

同時新增一條規則：**機會式補桶**（在資產接近前高時借款補滿現金桶，回撤期間只花不借）。這是把 v1 的水池策略套用到負債側。

---

## 1. 核心洞見（研究要據此設計，不是要驗證這句話）

先前手算的骨架，v2 要用真實資料重跑：

- 設 1 億、年借 250 萬（隨通膨成長）、利率 3%、資產名目 7%
- **LTV 不是單調下降**：前 26 年上升，峰值約 24.1%，之後才轉降
- 第 30 年遇到 −50%：質借派淨值 19,857 萬，直接賣股派 20,724 萬 → **三十年的槓桿優勢被一次崩盤完全抹平**
- 第 40 年做同樣測試：42,252 vs 35,709 → 優勢終於厚到吃得下一次崩盤
- 30 年累計名目支出 11,894 萬，期末負債 18,204 萬，其中 **6,311 萬是純利息**

所以這不是永動機的問題，是**「危險窗口有多長、你在窗口裡遇到什麼」**的問題。研究要輸出的是這個窗口的形狀，不是一個 yes/no。

> 附帶已確認的算術：用借來的錢付利息，與不付利息讓它資本化，在數學上完全等價（`D(t+1) = D(t)(1+r) + c` 兩種寫法同式）。任何策略設計不得把「利息付得出來」當成健康指標。

## 2. 三條抵押路徑

這是 v2 的主軸。每一條都要獨立參數化，不可共用預設值。

| | **Path A** 台股擔保 | **Path B** 海外券商 margin | **Path C** 009826 擔保 |
|---|---|---|---|
| 擔保品 | 0050 / 006208 | VT（美元） | 009826（台幣計價，全球） |
| 借款幣別 | TWD | USD | TWD |
| 利率 | 2.5–3.5%，機動，跟央行 | SOFR + 加碼，跟聯準會 | 2.5–3.5%，機動 |
| 歷史利率波動 | 台灣近 20 年相對平穩 | **0.25% → 5.5% 都發生過** | 同 Path A |
| 起始成數上限 | 約 5–6 成 | Reg-T 50%／Portfolio Margin 更高 | 未知，推測同 A |
| 強制平倉 | 維持率門檻（常見 130%，≈ LTV 77%），有追繳緩衝 | **自動平倉，不通知、無寬限** | 未知 |
| 額度可被抽回 | 是，逐年審核 | 否，但 margin 規則可變更 | 是 |
| 資產分散 | ✗ 單一市場 | ✓ 全球 | ✓ 全球約 40 國 |
| 與人力資本相關 | **極高** | 低 | 低 |
| 幣別匹配（債 vs 擔保品） | ✓ 完全匹配 | ✓ 同為 USD | **✗ 台幣債 vs 全球資產** |
| 資本利得稅 | 0（停徵） | 海外所得，計入基本所得額 | **0（境內證券）** |
| 配息 | 股利所得 | 海外所得 + 美國預扣 30% | **不配息** |
| 內扣 | 約 0.15–0.35% | 0.06% + 複委託 + 換匯價差 | **0.5%（規模逾百億）～0.6%** |

### 三條路徑各自的致命弱點（要在模型裡真的咬人，不是註解）

- **Path A**：便宜的錢綁定錯的資產。台股部位與 Clarence 的人力資本、幣別、居住地全部同向；台海尾端風險無法用配置對沖
- **Path B**：利率跟著美國跑。2022–2023 那種升息週期會讓 `r` 從 1% 跳到 5.5%，`g − r` 的利差**直接消失甚至轉負**，而這正好與市場下跌同時發生。自動平倉沒有人可以商量
- **Path C**：**匯率驅動的 LTV 風險**。負債是固定台幣金額，擔保品淨值隨匯率浮動。台幣升值 15% → NAV 下跌 → LTV 上升 15%，市場一動都沒動。這是 A、B 都沒有的風險，很容易被忽略

### Path C 的可行性是研究前置任務，不是模擬題

009826 於 **2026-08-03 掛牌**，掛牌至今約一週。以下必須先查證，查不到就把 Path C 標成假設性情境：

1. **各家銀行/券商的股票質借標的清單是否已納入**（多數要求上市滿一定期間與規模門檻）
2. 融資融券資格與時程
3. 可貸成數、維持率、利率實際報價
4. 實際內扣（含保管費與其他費用）、追蹤誤差、折溢價、買賣價差
5. **稅務確認**：境內 ETF 投資海外的資本利得免計入基本所得額；因不配息，理論上無配息端的海外所得問題——但請以當年度法規與會計師意見查證，模型中留 `tax_assumption_verified` 旗標

**若 Path C 質借尚不可行，這件事本身就是研究的主要結論之一**，要寫進報告首頁，而不是藏在附錄。

### 009826 的建模方式

沒有 live 資料，不可用一週的價格。做法：

```
r_009826(t) = r_ACWI_IMI_TWD(t) - fee_drag/12 - tracking_error(t)
```
- `fee_drag` 掃 `[0.5%, 0.6%, 0.75%]`（最後一個是壓力情境）
- 底層預扣稅：台灣無美台稅約，基金層級美股股息預扣 30%，需併入 drag 估算並在報告中列示推導
- `tracking_error` 以其他台灣發行之海外型 ETF 的歷史追蹤差距做參數化
- **明確標註這是合成序列**，所有 Path C 的結論都要加註「基於合成代理，無 live 驗證」

同時做 **VT vs 009826 的全成本對照表**（不含借款）：ER、底層預扣、投資人層預扣、複委託手續費、換匯價差、海外所得申報成本、再投入摩擦。這張表本身對決策就有價值——**009826 不配息 + 資本利得免稅，代表「直接賣股」這個對照組在稅務上是零摩擦的**，這會大幅提高質借策略要跨過的門檻。

## 3. 機會式補桶規則（v2 的核心新機制）

### 3.1 動機

年年固定借款的問題是：借款發生在時間上均勻分布，而 LTV 尖峰發生在崩盤時。機會式補桶把借款時點移到資產高點，代價是平均負債水位略高。**這是拿「較高的常態 LTV」換「較低的尖峰 LTV」**，模型要量化這筆交易划不划算。

### 3.2 規則定義

狀態：現金桶 `C`、負債 `D`、部位 `W`、當期支出 `s`

```
每月：
  1. 支出優先從 C 提取
  2. 若 C 不足，進入 fallback（見 3.4）

  3. 補桶判斷（僅用 t-1 以前資訊）：
     peak = max(W[0..t-1])
     if W[t-1] >= alpha * peak:
         target = N 年份的前瞻支出
         need   = max(0, target - C)
         cap    = max(0, LTV_max * W[t-1] - D)     # 不可讓 LTV 超過上限
         borrow = min(need, cap)
         D += borrow ; C += borrow

  4. 計息：D *= (1 + r/12)；現金桶：C *= (1 + r_cash/12)
```

### 3.3 參數掃描

| 參數 | 值域 | 說明 |
|---|---|---|
| `N`（桶深，年） | 0, 2, 3, 5, 7 | **N=0 是對照組**（年年借），必須跑 |
| `alpha`（前高門檻） | 0.90, 0.95, 1.00 | 1.00 = 只在創新高時補 |
| `LTV_max` | 15%, 20%, 25%, 30%, 40% | 自訂的軟上限，非銀行門檻 |
| `fallback` | F1 / F2 / F3 | 見 3.4 |

### 3.4 桶乾了怎麼辦（fallback，必須三種都跑）

- **F1 硬借**：不管前高條件，直接借。LTV 在最糟時點跳升
- **F2 賣股**：實現在低點，但不增加負債
- **F3 砍支出**：觸發 GK 的 capital preservation，撐到下次補桶條件成立

F3 是三者中唯一不擴大風險的，但它把成本轉嫁到生活水準。**這三個的差異就是「你願意在崩盤時付出什麼」，是整份研究最貼近真實決策的地方。**

### 3.5 現金桶的負 carry

桶內資金以 `r_cash`（台幣短率，約 1.0–1.5%）計息，資金成本 `r`（2.5–3.5%）。負 carry 約 1.5–2%/年。5 年桶 × 250 萬 = 1,250 萬，年漏約 19–25 萬。**這是保險費，不是最佳化收益**，報告要明白列出「保費」與「理賠」各是多少。

### 3.6 設計上的注意

- 「前高」用**部位市值**還是**淨值（W − D）**？兩者行為不同，建議兩種都跑並比較
- 槓桿部位的市值會持續創新高，`alpha=1.00` 在多頭裡幾乎每月觸發 → 退化成年年借。用 36 個月滾動高點會更穩健，一併測試
- 補桶不可在 LTV 已高於 `LTV_max` 時進行，這是硬約束

## 4. 信用額度風險模型（新增，v1 沒有）

現實中先咬人的往往不是維持率，是**額度被縮或不續約**。這是質借策略最被低估的風險，也是現金桶最大的價值來源。

```
每年審核：
  stress = (trailing_12m_return < -20%)
  p_cut  = p0 * (k if stress else 1)        # p0 掃 1~3%，k 掃 3~10
  若觸發：line_new = beta * line_old        # beta 掃 0.5 / 0.7
  若 D > line_new：須於 T 日內償還差額
      → 現金桶足夠：動用桶，存活
      → 不足：強制賣出（含滑價），可能實現在低點
```

Path B 沒有額度抽回，改為 **margin 規則變更**（維持率門檻上調）與**自動平倉**（無寬限期、無現金桶可用的緩衝時間）。這個差異要如實反映：**Path B 的現金桶必須放在券商帳戶內才有救援效果**，否則平倉先發生。

**假說 H10：現金桶對「額度被抽」的保護效果，遠大於對「市場回撤」的保護效果。** 若成立，補桶規則的設計目標就該重寫。

| H9 | 機會式補桶相對年年借，能降低多少尖峰 LTV／強制平倉機率？負 carry 的成本是否值得？最適 `N` 與 `alpha` 是多少？ |
| H10 | 現金桶的主要價值來自「避免在低點借款」還是「應對額度被抽」？ |
| H11 | 在 009826 存在（賣出零稅、不配息）的前提下，質借相對直接賣出還剩多少優勢？**若答案接近零，整條質借路線就該放棄。** |

**H11 是全案的判決點。** 質借在台灣的稅務誘因是零（本國證券資本利得免稅），剩下的全部價值就是槓桿。而槓桿可以用更簡單、無追索、無額度風險的方式取得。研究要誠實回答：這麼複雜，換到了什麼？

## 6. 策略矩陣擴充

在 v1 的 `P1–P5` 之外新增：

- `P6a` 100% 台股（0050）+ Path A 質借提領
- `P6b` 100% VT + Path B margin 提領
- `P6c` 100% 009826 + Path C 質借提領
- `P7` 混合：核心部位不質借 + 一小塊衛星部位質借（LTV 天花板更低）
- `P8` 對照組：**009826 直接賣出**（零稅、零利息、零額度風險）— 這是質借必須打敗的基準線

每一條 `P6*` 與 `N`、`alpha`、`LTV_max`、`fallback` 做 factorial，先跑篩選層再展開。

## 7. 指標擴充（在 v1 §5 之上）

新增：
- **P(強制平倉)** 與 **P(額度被縮且無法應對)**，分開計數
- **首次觸線的年份分布**（危險窗口的實證形狀）
- **尖峰 LTV 分布**（中位數、95th、99th）
- **累計利息支出／累計實質支出** 之比（成本透明度）
- **淨值路徑的最大回撤**（不是部位回撤——槓桿下兩者差很多）
- 崩盤情境下的**條件比較**：以「發生 ≥40% 回撤」為條件，比較各策略的條件期望淨值

報告中的每一個「質借勝出」結論，都必須同時列出對應的 P(強制平倉)。**不得只報期望值。**

## 8. 防自欺協定增補（v1 §6 全部沿用）

8. **借款決策不得使用當期資訊**：補桶觸發只能用 `W[t-1]`。寫一個故意違規的測試確認 assert 會攔下
9. **利率不可設為常數**：`r` 必須來自同一條抽樣時間軸（Path A/C 用台灣利率序列，Path B 用美國）。固定利率的結果只能當敏感度參考，不可當主結果
10. **匯率必須綁在同一條時間軸**：Path C 的 LTV 對匯率敏感，這條不做，H8 就是假的
11. **手算對照**：用 §1 的確定性參數（1 億／250 萬／3%／7%）跑一次零波動情境，必須複現 LTV 峰值 24.1% @ 第 26 年、第 30 年淨值 57,918 萬。對不上就是引擎有問題
12. **Path C 所有結果標註合成代理**，圖表上要看得見

## 9. 報告額外要求

`REPORT.md` 除 v1 的結構外，開頭新增一節 **「先回答三個是非題」**：

1. 009826 目前能不能質借？（事實查證，不是模擬）
