重現：`python data/build_trend.py && python run_v4_stack.py`（約 2.5 分鐘）。
輸出：`results/v4_stack.csv`（主表）、`v4_stack_regimes.csv`（歷史體制窗）、`v4_stack_sens.csv`（利差 × 趨勢折扣）。
測試：`python tests/test_stack.py`（代理訊號無前視、零疊加恆等式、費用算術、平滑指標）。

**先講結論的可信度：** 本節所有「疊加贏」的來源只有一個——趨勢序列 1985 年後是 AQR 的毛報酬假設性因子（超額報酬 12.25%/年、Sharpe ≈ 0.98），
1985 年前是我們自己拼的 2 資產代理（與 AQR 重疊期相關係數僅 0.37）。可投資的趨勢指數（SG Trend 類）Sharpe 大約 0.3–0.5。
**把 §5 的「趨勢折扣 0.5」當中心案例讀，折扣 1.0 是理想化上限。**

**理想化上限聲明：** 無追蹤誤差、無清算／保證金風險、槓桿月頻再平衡（真實 ETF 為日頻）、無期貨轉倉與買賣價差、AQR 因子為毛報酬。實際數字只會更差。

## 6. §7.2 四題與 §12 Q6

**Q1 1966–1982 通膨體制：公債疊加與趨勢疊加各自是幫忙還是放大損失？**
公債疊加放大損失：債−bill 17 年累積 −20%，RSSB 實質 −30%（VT −3%），最大回撤 −60%。趨勢疊加是幫忙的（RSST +147%），但那一段的趨勢是自建代理，
且五五配的 +43% 幾乎全由它貢獻——**在通膨體制裡，五五配的「保護」100% 押在趨勢腿上，而趨勢腿正是四條序列裡最不可信的一條**。

**Q2 2022 型股債同跌：趨勢那一半補回多少？**
補回非趨勢部分損失的 **50%**（半份趨勢 +11.8pp vs 股 + 半份債 −23.8pp）。淨效果：五五配 −18.5% 實質，僅比 80/20 好 1.7pp；趨勢半份剛好抵掉債券半份的額外損失。
全份趨勢（RSST）才真正保住（−0.7%），全份債（RSSB）則多跌 14pp。

**Q3 搭配 VPW：槓桿組合的支出波動是否大到抵銷總量優勢？**
不至於（在折扣 ≥ 0.5 下）。五五配 VPW3 支出年變動率 .214 vs 80/20 .141（+52%），但支出最大回撤較淺（−38% vs −46%）、低於高點 80% 的年數較少（8 vs 14），
CE γ2/4/8 全勝。原因是高漂移：波動大但一直往上，回撤被填掉。折扣 0 時漂移消失，波動留下，γ4/γ8 轉負——**支出波動本身不是問題，沒有溢酬的波動才是**。

**Q4 與 80/20 VT+BND 在 CE γ∈{2,4,8} 的排序？**
折扣 1.0：五五配 +.076 / +.027 / +.023，全勝。折扣 0.5：+.040 / +.015 / +.011，仍勝。折扣 0.25 + 利差 0.5%：+.016 / +.001 / −.003，持平到輸。折扣 0：+.006 / −.006 / −.008，γ≥4 輸。
**排序取決於未來趨勢毛超額報酬是否 ≥ 約 3%/年**；不穩健。

**§12 Q6 RSSB + RSST 在壓力樣本下，是放大報酬還是放大損失？**
分開看：**RSSB（債券疊加）在通膨型壓力（1966–82、1973–74、2022）一律放大損失**，只在通縮型崩盤（2000–02、2008）幫忙；
**RSST（趨勢疊加）在五個窗全部放大報酬**——這個「五戰五勝」本身就該起疑：1985 年前是自建代理，1985 年後是 Sharpe ≈ 1 的毛因子。
五五配把兩者對沖成「比 80/20 略好一點的壓力表現 + 遠高的中位數」，但整包優勢的來源只有趨勢溢酬，把它砍到可投資水準（Sharpe 0.25–0.5）優勢就縮到零附近。
結論：**它放大的是「對趨勢溢酬的曝險」**——溢酬在就放大報酬，溢酬不在就是一個多付 0.69% 費用、多扛 50% 債券久期的 100% 股票。
