## 粗估年化總持有成本（買進後長抱，不含交易）

- **VT**：0.06% + 投資人層預扣 ~0.6% ≈ **0.65–0.7%/年**（配息全部被預扣 30% 是大宗）
- **009826**：0.5–0.6% + 基金層預扣 ~0.36% + 追蹤誤差 0.2–0.5% ≈ **1.05–1.45%/年**

兩者差距約 **0.4–0.8%/年**,方向不定於直覺：009826 的高內扣被「不配息 + 免投資人層預扣 +
賣出零稅」部分抵銷。**對提領期投資人（每年要賣）**,009826 的賣出零稅是結構性優勢；
**對累積期投資人**,VT 的低內扣佔優。此表的決策意涵（v2 §2 原文）：

> 009826 不配息 + 資本利得免稅，代表「直接賣股」這個對照組在稅務上是零摩擦的，
> 這會大幅提高質借策略要跨過的門檻。

亦即:**質借在台灣的稅務誘因是零**（賣 009826 本來就不課稅），質借剩下的價值只有槓桿本身
與「不實現損益」的時點選擇權——這正是 H11 要量化的東西，見 REPORT。
