# Handoff v3：先修計分，再補跑

延續 v1、v2。引擎已驗證正確（手算複現 LTV 峰值 24.14% @ 第 26 年、NW30 = 5.7918；文獻關卡 97.9%；無前視測試含作弊偵測）。**v3 不動引擎，動的是計分方式與缺跑的格子。**

優先序是刻意的：§1 的計分不修，§2 之後跑再多都會得到錯誤排序。

---

## 1. 最高優先：支出失敗的定義壞了

### 1.1 問題

現行定義：`實質支出 < 初始支出 × 70%，連續 ≥3 年`。

分母是**該策略自己的初始支出**。所以 GK3 的門檻是初始資產的 2.1%，GK5 的門檻是 3.5%——**兩者在用不同的及格線比及格率**。起始率越低，門檻自動下移，「支出失敗率」自動變好看。這是計分作弊，不是策略改善。

這直接影響「GK3 會不會更好」這個問題：現行計分下它一定看起來更好，但那是假的。

### 1.2 修正

失敗門檻改為**絕對值，以初始資產為單位**：

```
floor_abs ∈ {1.5%, 2.0%, 2.5%, 3.0%} × W0   # 實質，隨通膨調整
支出失敗 = 實質支出 < floor_abs，連續 ≥3 年
```

同一條門檻套用到所有策略、所有起始率。這樣 GK3 / GK4 / GK5 / 固定 4% / VPW 才在同一把尺上。

### 1.3 連帶要重跑

- 起始提領率掃描擴大到 **2.0%–5.0%，步長 0.25pp**（v2 只掃 2.5–5.5 且用舊計分）
- 每個 `floor_abs` 各出一張主表。**預期結論會隨 floor_abs 翻轉**——那就是答案，不是問題
- v1 報告「起始提領率是幻覺」這個結論必須用新計分重驗。若它在絕對計分下仍成立，它會變得更有力

### 1.4 先驗預期（要被檢定，不是被假設）

依 v2 已有的掃描（p5 終身支出隨起始率 2.5%→5.5% 從 1.05 升到 1.24），**GK 的破產率在任何起始率下都是 ~0，所以「成功率更高」在破產維度上不可能成立**；GK3 相對 GK5 應該是**絕對終身支出更低**。若新計分下 GK3 反而勝出，要找出機制才能採信。

---

## 2. 第二優先：桶的因果歸因錯了

### 2.1 問題

v2 台灣引擎表裡：

| | 強制事件 | 尖峰LTV 中位 | 勝過賣股 |
|---|---|---|---|
| N0（不設桶） | 4.9% | 17.6% | 97.6% |
| N3-F1（設桶，乾了硬借） | **5.2%** | **21.2%** | **97.3%** |

**N3-F1 每一欄都不如 N0。** 補桶機制本身是負貢獻（提早借款推高負債水位），保護全部來自 fallback。而 F3 就是 GK 減支。

現行 H9 的表述（「保費划算，理賠用生活水準付」）因果顛倒了：不是桶貴，是**桶沒用**，付錢的是減支。

### 2.2 修正：正交因子設計

```
bucket ∈ {OFF, N2, N3, N5}
fallback ∈ {F1 硬借, F2 賣股, F3 砍支出}
```
完整 4×3 factorial，**含 bucket=OFF × 各 fallback**（v2 缺這三格，所以無法歸因）。

輸出一張二維邊際效果表：桶的主效果、fallback 的主效果、交互作用。若桶的主效果 ≤ 0，H9 要改寫成「桶無效，保護來自減支規則」。

---

## 3. 累積期完全沒跑

v1 規格的 `A1–A5`（固定 60/40、80/20、100/0、bond tent、rising glide）**一格都沒有結果**。目前兩份報告全是提領期。

原始問題是「累積期與提領期」，所以這是最大的缺口。補跑時：

- 累積期長度掃 `20 / 30 / 40` 年
- 必須含 **H4：收入中斷 × 股災相關**（v1 §3.1，至今未跑）。這是累積期唯一真正的破產機制
- 銜接方式：累積期終值分布 → 提領期起點，**不可用中位數當單點**。整條分布往下接
- 輸出「累積配置 × 提領規則」的聯合表。可能出現的非直覺結果：累積期較保守的配置雖然終值較低，但終值分布較窄，反而讓提領期的 p5 更好

## 4. Path A：資料你已經有了

v2 的 H7 寫「Path A 未能量化（無台股 TR 序列）」——但序列存在，在信貸專案裡：

- 1997–2002：加權指數 + 證交所年報市場殖利率近似
- 2003 起：官方報酬指數
- 2009 起：0050 本人
- 已做重疊期驗證（月相關 0.9953、逐年差平均 1.3pp，方向偏保守）

直接接入。沒有 Path A，v2 的核心命題「便宜的錢 vs 對的資產」只是修辭。

同時要輸出 Path A 專屬的診斷：**台股部位與人力資本、幣別、居住地同向**。建議加一條情境：台股在某段期間額外承受 −30% 的地緣衝擊（外生，不從歷史抽），看 LTV 與強制事件如何反應。標明這是情境不是機率估計。

---

## 5. 支出地板可壓縮比例（v1 §3.2，仍未跑）

現在比任何時候都關鍵，因為 §2 顯示 **F3 承擔了質借策略的全部保護**，而 F3 需要支出砍得下去。

```
floor_ratio = 不可壓縮支出 / 總支出  ∈ {0.2, 0.35, 0.5, 0.7}
動態規則只能砍 discretionary 部分
```

預期發現：`floor_ratio` 超過某個值時，GK 與 F3 同時失效，整個「動態規則」家族崩塌。**找出那個值。** 這是全案唯一由使用者決定、而非由資料決定的參數。

---

## 6. 中性提領法（v1 的 W4–W6，仍未跑）

目前動態規則只有 GK 和 Vanguard 動態，而 F3 用的也是 GK。**GK 的地位可能只是因為對手沒到場。**

補跑：

- `W4` **VPW / 攤銷法**：每年依剩餘年期與假設報酬重算。參數只有 2 個，且來自恆等式而非回測擬合
- `W5` **RMD 式**：依生命表提領當期資產的固定比例。參數 0 個
- `W6` **funded ratio 護欄**：以「資產 / 剩餘終身支出現值」觸發，而非提領率

這三個是「最少替使用者做決定」的一組。若 GK 在絕對計分下仍勝出，那個勝利才有意義。

---

## 7. 新家族：地板 + 上檔

目前矩陣裡完全沒有這一類，而它可能才是高 `floor_ratio` 使用者的正解：

- `S1` 勞保 + 勞退年金當地板（實質金額參數化，**必跑足額 / 打七折 / 歸零 三情境**）
- `S2` 台幣公債 / 定存階梯覆蓋地板支出 20 年，其餘 100% 股票
- `S3` 遞延年金（若台灣有可用商品；查不到就標為假設性）
- `S4` S1 + S2 疊加

比較基準：這一族的 p5 應該遠高於任何動態規則，代價是中位數較低。**若代價小於預期，這一族會直接支配動態規則家族**，那會是本研究最大的結論翻轉。

## 8. 讓它更接近真實的模組

按「改變結論的可能性」排序，不是按有趣程度。

### 8.1 死亡率（最該做，成本最低）
目前把「活滿 50 年」當確定事件。真實的問題是「**錢在你還活著時用完的機率**」。

```
用台灣生命表，模擬存活年數（單身／雙人聯合）
主指標改為：P(資產耗盡 且 仍存活)
```
影響方向：對 65 歲退休者，固定 50 年大幅高估風險；對 40 歲 FIRE 者則低估。**這會改變不同年齡層的最適解，而目前的報告對兩者給同一個答案。**

### 8.2 退休支出微笑曲線
真實退休支出不是水平線：前期高（go-go）、中期降（slow-go）、後期因醫療回升（no-go）。以實質支出 −1%/年、75 歲後 +2%/年 之類的形狀參數化並掃描。

影響方向：微笑曲線讓固定提領看起來比現在好（因為真實支出本來就會降），**削弱動態規則的相對優勢**。這是目前對 GK 有利的一個隱藏偏誤。

### 8.3 一次性大額支出
換房、子女教育、長照。以低機率抽取大額衝擊，並測「衝擊剛好落在崩盤期」的條件情境。這是現金桶唯一可能真正有價值的場景——目前沒測到。

### 8.4 行為棄守（v1 §3.8，仍未跑）
```
若回撤 > X% 且持續 > Y 月 → 以機率 q 全部轉現金，之後以機率 m/月 回場
```
影響方向：對 100/0 與 GK 偏樂觀（兩者都要求在最痛時照規則執行）。**這是唯一能把「你會不會照做」從免責聲明變成數字的地方。**

### 8.5 稅與費用（v1 要求，仍未跑）
海外所得 100 萬 / 750 萬門檻、ETF 內扣、換匯價差、再平衡成本。高周轉策略（GK、桶、質借）相對更受傷。

### 8.6 樣本延長
Shiller 資料止於 2023-07。補到最新，並註明 2024–25 多頭會讓所有數字變好看——**報告要同時給含與不含的版本**，避免用近期多頭美化結論。

## 9. 未解的方法論問題

### 9.1 H2 仍然無效
全球股用 S&P 代理 = 用美國倖存者偏誤去驗證一篇專門修正該偏誤的論文。**JST 18 國面板（或 DMS）不跑，「Cederburg 派得到支持」這句話不能寫。**

### 9.2 台灣引擎的樂觀偏誤不是均勻的
v2 自己的數字：利息/終身支出在台灣樣本 ~0.4 倍，美國壓力樣本 0.8–1.1 倍（40 年 N3-F3 是 **1.38 倍**）。

賣股派在仁慈樣本被高估的是報酬；質借派被高估的是報酬**加上**利差。所以兩者不能同等折價。v3 要出一張**逐策略的偏誤敏感度表**：把台灣引擎的報酬與利率各自向壓力樣本靠攏，看排序在哪一點翻轉。

### 9.3 H8 反事實未做
Path C 唯一獨有的風險是匯率驅動 LTV。固定匯率跑一遍即可，成本極低。

### 9.4 CRRA 只報了 γ=4
v1 要求 γ ∈ {2,4,8}。只報對 GK 最有利的那個值，讀起來像挑選。**排序若隨 γ 翻轉，那本身就是結論。**

## 10. 一個該被拉出來當頭條的數字

美國壓力樣本 40 年 N3-F3：**利息中位數 = 終身支出的 1.38 倍**。

四十年下來，你付給銀行的利息比你花掉的生活費還多。這個數字現在埋在表格裡，v3 要讓它出現在質借那一節的第一段。

## 11. 交付順序建議

1. §1 計分修正 + 提領率 2.0–5.0% 重掃 ← 沒這個，後面全部排序不可信
2. §2 桶的正交因子（便宜，直接改寫 H9）
3. §5 支出地板掃描（決定使用者能不能用動態規則）
4. §6 中性提領法 + §7 地板+上檔（補齊候選集）
5. §8.1 死亡率（改變不同年齡的答案）
6. §3 累積期 + H4
7. §4 Path A
8. §9 方法論修補
9. §8.2–8.6 其餘真實性模組

前三項做完，決策上大概就夠用了。

## 12. 提醒

- 任何在絕對計分下消失的優勢，都不是優勢
